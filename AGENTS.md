# Ready product guardrails

1. Ready is about dependencies, not habits.
2. Show what is different today.
3. The user is the hero; Ready is the guide.
4. Reduce cognitive load instead of adding tasks.
5. Infer when confidence is high; ask when uncertain.
6. Explain why every inferred recommendation exists.
7. Never pretend certainty where data is incomplete.
8. User corrections override system assumptions.
9. Sleep changes information load, not medical guidance.
10. Build responsive web interfaces that naturally transition to mobile.

Keep providers independent from UI. Never expose provider credentials to client code. Phase 1 stays deterministic and works fully in demo mode.
